### I build the whole interface layer

I am a frontend engineer who likes owning the complete product surface—from semantic HTML, CSS architecture, and browser APIs to framework-scale applications, native-feeling mobile experiences, and packaged desktop software.

I can start with plain HTML, CSS, and JavaScript when that is the right tool, then scale the same product thinking through React, Next.js, Vue, Nuxt, React Native, or Electron. I do not see frontend as simply turning a design into pages. It includes state, data flow, performance, accessibility, motion, internationalization, build systems, and every loading or failure state between an idea and a dependable release.

My favorite work lives where design and engineering overlap: complicated workflows made understandable, cross-platform products that still feel native, and interfaces whose polish comes from hundreds of small, deliberate decisions.

### What I can own end to end

- Turn a rough brief or Figma file into a responsive, accessible product interface.
- Choose application boundaries, state strategy, API contracts, caching, and recovery behavior.
- Build shared components and design tokens without turning the system into an abstraction maze.
- Diagnose rendering, bundle, network, interaction, and memory performance issues.
- Package React Native and Electron products around platform constraints instead of fighting them.
- Set up testing, error visibility, internationalization, and release workflows that survive production.

### Engineering values

- Start with the smallest product loop that proves the idea.
- Treat loading, empty, failure, and recovery states as first-class UI.
- Use the platform before adding a dependency; use a framework when the product earns it.
- Keep architecture proportional to the problem—simple until complexity earns its place.
- Make motion explain state and hierarchy, not merely decorate the screen.
- Optimize for the next change, not only the current screenshot.
- Ship, observe, refine, and leave the codebase easier to change than I found it.
